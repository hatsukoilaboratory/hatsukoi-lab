## 容量最適化 v1

元ZIP由来のWebP 46枚、合計12,157,410 bytesを原本として保持し、最大幅1280px・WebP quality 80・method 6で再圧縮しました。最適化後は8,283,030 bytesで、合計31.87%（3,874,380 bytes）削減されています。1600px幅の漫画画像は1280px幅へ縮小し、1200px以下の画像は主に再圧縮のみを行いました。

銀髪・大学同期・配信者・水城・小糸・なっちゃんの代表画像を再圧縮前後で比較し、顔、輪郭、吹き出し、漫画の細線に明確な破綻がないことを確認しました。最適化版46枚へ`works.ts`の参照を差し替え、スマホ390px幅の銀髪・小糸・水城作品ページでも画像表示と横スクロールビューアを確認しています。
