# 独立静的配信の検証メモ

`dist/public`のみを、プロジェクトの開発サーバーとは別のローカル静的HTTPサーバー（`127.0.0.1:4173`）で配信して確認した。

| 確認対象 | 結果 | 確認内容 |
|---|---|---|
| `/works/ginpatsu` 直接アクセス | OK | ロゴ、ヒロイン画像、サンプル、ストアロゴ、フッターを`/assets/`から表示。 |
| `/diagnosis` 直接アクセス | OK | 道庭・鳴海の顔写真、スタンプ、診断開始導線、フッターを`/assets/`から表示。 |
| 公開ルート一括検証 | OK | `/`、`/heroines`、`/diagnosis`、`/commission`、9作品ページの計13ルート。 |
| アセット一括検証 | OK | アセットマニフェスト記載の115ファイル。 |
| dist内Manus文字列監査 | OK | `/manus-storage/`、Manusドメイン、runtime、debug collector、環境変数参照は0件。 |

静的サーバーは拡張子を持つ未知のURLを404で返し、それ以外のパスは`index.html`へフォールバックするため、SPAの直アクセス・リロードを検証できる。
