# 販売リンク照合メモ

## 現行データ

`client/src/data/works.ts` の現行本編8作品は、FANZAの提示順に対応してDLsiteとBOOTHを並べている。具体的には、DLsiteのRJ01323373〜RJ01447671、BOOTHの6476010〜7284886が先頭8作品へ順番に割り当てられ、RJ01493254 / BOOTH 7575184 は銀髪・後輩・ボクっ娘・同期・配信者の後日談CG集、RJ01633092 / BOOTH 8483665 は銀髪ちゃん続編漫画として銀髪作品へ登録されている。

## 外部照合

DLsiteの直接URLは自動的に `https://www.dlsite.com/home/` へリダイレクトされ、商品タイトルを取得できなかった。BOOTHの先頭4 URLは年齢確認ページを返し、年齢確認前の本文には商品タイトルが含まれなかった。そのため、外部ページの自動取得だけでは商品名の最終照合ができない。ユーザーが提示したURLの順番とFANZAの正しい作品順を、現時点で最も信頼できる対応表として扱う。

## 公開サイト実href

公開中の `/works/ginpatsu/` では、本編が FANZA `d_508321` / DLsite `RJ01323373` / BOOTH `6476010`、後日談が FANZA `d_559827` / DLsite `RJ01493254` / BOOTH `7575184`、続編が FANZA `d_573388` / DLsite `RJ01633092` / BOOTH `8483665` と描画されている。ソースと公開サイトの銀髪作品は一致している。

BOOTH `items/6522126` は「健気で元気っ子な後輩と甘々初えっち」、`items/6569552` は「巨乳ボクっ娘幼馴染と甘々初えっち」と確認でき、現行のFANZA順・DLsite順・BOOTH順と一致する。

BOOTH `items/7575184` は「君と僕の額縁」で水城友結本編、`items/8483665` は「100日後にチャラ男のキープちゃんを幸せにした話」で佐瀬小糸本編に対応する。BOOTHの正しい対応は、ai=`7284886`、mizuki=`7575184`、koito=`8483665`、銀髪後日談CG集=`6764185`、銀髪続編=`6831880`。
